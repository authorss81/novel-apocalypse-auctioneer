3. **A hyphenated token contributes tens plus units at one step**, so `sixty-nine` is 69 and `twenty-first` is 21, and a hyphenated compound adds to the hundred rather than replacing it.
4. **A number of value zero is kept**, because a parser that tests the parsed value for truth instead of for presence loses every morning a count stood at nothing.
5. **A hundreds parser adds `one hundred and six` as 106 and does not replace it with 6.**
