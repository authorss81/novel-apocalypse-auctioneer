One file per completed batch, named `batch-NNNN-review.md`. A review file records what each review pass found, what it fixed in the prose, which approved card beats the prose declined, and which findings belong to the pipeline owner rather than the writer.

Review records are audit history, not story state. Nothing here should be loaded to write prose. The handoff a writer needs is `state/batch-000N-summary.md`; a reviewer reads both.
