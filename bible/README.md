# Bible

Author-facing canon for *The Apocalypse Auctioneer*. These files define the world, people, power limits, thematic questions, and vocabulary before chapter prose is drafted.

## Files

- `premise.md` — one-sentence premise, protagonist contract, central promise, and genre boundaries
- `world.md` — geography, history, Fault rules, factions, and concrete object examples
- `characters.md` — protagonists, relationships, antagonist ladder, and arcs
- `power-system.md` — Tally mechanics, readings, growth stages, costs, and failure modes
- `themes.md` — recurring moral and emotional questions
- `terminology.md` — canonical terms, names, rules, and Tally display style

No chapter prose belongs in this directory. Any new canon rule must be recorded here before it is used in a chapter batch.
